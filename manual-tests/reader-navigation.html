Reader navigation test article

This deliberately long article exercises reader extraction while the navigation controls use no rel attributes. The previous control exposes its meaning through aria-label, the contents control through title, and the next control only through its icon class. The paragraph is repeated in meaning so that article extraction has enough real text to select this element as the primary readable content.

A robust reader should preserve useful chapter navigation without depending on one website convention. It should accept accessibility metadata, structural names, icon semantics, normal links, JavaScript links, and button-driven navigation while avoiding carousel and gallery controls that happen to use the same words. These controls provide a compact browser-level regression fixture for those expectations.
